# Run 5 — Unlock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Quick look, Reply mode, and grant extensions with one **Unlock** mode (1, 2, 5, or 10 minutes, chosen at the gate, priced by a doubling streak), add a 30-second warning before an Unlock ends, migrate 0.1.0 state files, and give myTime an app icon.

**Architecture:** All Unlock rules live in `MyTimeCore`: one pure pricing function (`UnlockPricing`) used by the gate, the panel, and the purchase, so the price shown is the price charged. An Unlock is not a grant: it is one `ActiveUnlock` in `PersistedState` that covers every app with the `.unlock` mode, and it finishes in update step 5 next to grant expiry. Migration from schema 1 runs on the JSON payload after the HMAC check, so a valid old file never looks tampered.

**Tech Stack:** Swift 6 toolchain in Swift 5 mode, SwiftPM, XCTest, AppKit + SwiftUI. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-13-mytime-design.md` (revision 8, written in Task 1). Source proposal: "myTime Proposal — Token System Changes" (2026-10-23). If the plan and the spec disagree, the spec wins; report the conflict in `IMPLEMENTATION_NOTES.md`.

## Decisions

These were settled with the user on 2026-10-24 and go into the spec in Task 1.

**Scope**
- Unlock replaces Quick look, Reply mode, and grant extensions. Booked sessions and Emergency are unchanged, except that an Emergency pill no longer offers an extension (nothing can be extended).
- One Unlock at a time. It covers every blocked app whose modes contain `.unlock`. Opening such an app during an Unlock just launches it. An app without `.unlock` shows its normal gate.
- **No pill for Unlocks.** The menu bar shows the time left (like booked sessions); the 30-second warning covers the end. Emergency grants (and leftover 0.1.0 Quick look/Reply grants) keep the pill, without the extend button and without the reply note line.
- **The gate pause grows during a streak:** `pause = max(gatePauseSeconds, min(Constants.gatePauseCap /*30*/, gatePauseSeconds × nextMultiplier))` for apps with `.unlock`; apps without `.unlock` use `gatePauseSeconds`. It is fixed when the gate opens.
- **Booking top-up is out of scope** for this run.
- **App icon** is in scope (Task 5). Remove "A custom app icon" from spec §14.

**Rules**
- Lengths: `Constants.unlockLengthUnits = [1, 2, 5, 10]`; `lengthSeconds = units × Constants.unlockSecondsPerUnit` (60 release, 10 DEV).
- Price: `cost = units × multiplier`.
- Multiplier for an Unlock bought at time `t`, given the previous Unlock `p` (`UnlockStreak`): `2 × p.lastMultiplier` when `p.dayKey == dayKey(t)` and `t − p.lastEnd < Constants.unlockStreakGap` (900 release, 30 DEV); otherwise 1. No cap.
- `p.dayKey` is the day key of the previous Unlock's **purchase** time. (So an Unlock bought at 3:55 AM that ends at 4:05 AM still belongs to the old day, and the proposal's 3:55 → 4:10 case gives 1×.)
- While an Unlock is active, "previous" is the active Unlock itself (its multiplier, its scheduled end, its day key), so the panel and the warning can show the next price.
- `lastEnd` is the Unlock's scheduled end, or the moment **End Unlock** was pressed if earlier. Late processing (sleep, relaunch) never moves it.
- `resetsAt = min(p.lastEnd + unlockStreakGap, nextDayStart(after: t))`, only when the multiplier is above 1.
- Requirements to buy, checked in this order: app is blocked (`.unknownApp`), app has `.unlock` (`.modeNotAllowed`), not focusing (`.focusActive`), no active Unlock (`.unlockActive`), length is one of the offered lengths (`.invalidLength`), `expectedCost` equals the current price for that length (`.priceChanged`), enough tokens (`.notEnoughTokens`).
- No refunds, no extensions. **End Unlock** sets `endedAt = now`; the follow-up update finishes it.
- Finishing (update step 5, after grant expiry): when `endedAt != nil` or `now ≥ endsAt`, record the streak, history, and stats, clear `state.unlock`, and emit `.terminateIfNotAllowed` for **every** app with `.unlock` plus `.unlockEnded`.
- Warning (update step 5, after finishing): for an active, unwarned Unlock with `remaining ≤ lead` where `lead = min(Constants.unlockWarningLead /*30 s; DEV 5 s*/, lengthSeconds / 2)`:
  - if `remaining < Constants.unlockWarningMinimum` (5 s release, 2 s DEV): set `warned = true`, emit nothing;
  - else if some running app has `.unlock` and is **not** kept open by a booking at the Unlock's end: set `warned = true`, emit `.unlockWarning`;
  - else: do nothing yet (a covered app may still be opened).
  - "Kept open by a booking at the end" = the app has `.booked` and some booking that is not canceled and not ended early satisfies `start ≤ endsAt < end`.
- Booked sessions and Emergency neither count toward nor reset the streak.
- Wake-ups: active Unlock → `endsAt` (critical); unwarned → `warningAt = endsAt − lead` (non-critical).

**Stats and history**
- `DailyStats` and `WeeklyStats` gain `unlocks: Int`, `unlockSeconds: Double` (time actually used), `unlockTokens: Int`, `highestMultiplier: Int`. Count, tokens, and highest multiplier are recorded at purchase (today / this week). Used seconds are recorded when the Unlock finishes, to the Unlock's purchase day and week.
- `DailyStats` and `WeeklyStats` decode every field with `decodeIfPresent(…) ?? default`, so 0.1.0 files load before and after Task 4.
- `HistoryKind` gains `unlockBought` and `unlockEnded`. Old `quickLook`, `reply`, and `extended` kinds stay so old events keep their labels.
- `GrantKind` keeps `quickLook` and `reply` for grants left over from 0.1.0. Nothing creates them after Task 4.

**Migration (Task 4)**
- `Constants.schemaVersion = 2`. `StateCodec.decode` verifies the MAC, reads `schemaVersion`; 1 → migrate the JSON payload, then decode, returning `.migrated(state)`; 2 → `.ok(state)`; anything else → `.tampered`.
- `StateStore` saves a `.migrated` state immediately.
- Per app: modes become `[.unlock]` if the old modes had `quickLook` or already had `unlock` (a schema-1 file saved by a Task 2–3 build), plus `[.booked]` if they had `booked`. `reply` alone does not enable Unlock. Pending `setMode` changes for `unlock` are kept as is.
- Pending `setMode` with mode `quickLook` → same item with mode `unlock`, same `applyAt`, summary re-rendered as `"Turn on Unlock for <App>"`. Pending `setMode` with mode `reply` → dropped. Pending `setNumber` for a removed key → dropped. Everything else unchanged.
- `settings.numbers` loses the five removed keys. `daily[*]` loses `quickLooks` and `replies`.
- Grants, tokens, progress, bookings, stats, and history carry over. `unlock` and `unlockStreak` start empty, so the first Unlock costs 1×.
- `migrationNotice` is set (copy below) and shown once in the panel until dismissed.

**DEV values** (`#if DEV_TIMESCALE`): `unlockSecondsPerUnit` 10 (lengths 10, 20, 50, 100 s), `unlockStreakGap` 30, `unlockWarningLead` 5, `unlockWarningMinimum` 2. `unlockWarningMinimum` 2 (not 5) is our choice so the DEV warning can show at all; the proposal doesn't give a DEV value.

    public var endsAt: Date
    public var lengthSeconds: Int
    public var multiplier: Int
    public var cost: Int
    public var dayKey: String       // day key of startedAt
    public var warned: Bool
    public var endedAt: Date?       // set by endUnlock(); finished by the next update

    public var warningAt: Date { get }                  // endsAt − min(unlockWarningLead, lengthSeconds / 2)

    public var lastMultiplier: Int
    public var lastEnd: Date

    public var units: Int
    public var lengthSeconds: Int
    public var cost: Int
}
public struct UnlockQuote: Equatable {
    public var multiplier: Int
    public var options: [UnlockOption]
    public var resetsAt: Date?          // nil when multiplier == 1

/// Discord (Unlock + Sessions), TextEdit (Unlock only), Notes (Sessions only).
struct UnlockFixture {
    var core: EngineCore
    var sim: Sim
    let discord: UUID
    let textEdit: UUID
    let notes: UUID

    @discardableResult
    mutating func advance(to target: Date) -> UpdateResult {
        sim.advance(target.timeIntervalSince(sim.wall))
        return core.update(sim.input)
    }

    /// Buys at the price currently quoted for that length.
    @discardableResult
    mutating func buy(_ lengthSeconds: Int, app: UUID? = nil) throws -> ActiveUnlock {
        let option = core.unlockQuote(at: core.now).options.first { $0.lengthSeconds == lengthSeconds }
        return try core.buyUnlock(appID: app ?? discord, lengthSeconds: lengthSeconds, expectedCost: option?.cost ?? 0)
    }
}

import XCTest

@testable import MyTimeCore

final class UnlockPricingTests: XCTestCase {
    private let day = "2026-09-14"
    private let dayStart = date(2026, 9, 15, 4)

    func testFirstUnlockOfTheDayIsOneTimes() {
        let quote = UnlockPricing.quote(after: nil, at: date(2026, 9, 14, 14), dayKey: day, nextDayStart: dayStart)
        XCTAssertEqual(quote.multiplier, 1)
        XCTAssertEqual(quote.options.map(\.lengthSeconds), [60, 120, 300, 600])
        XCTAssertEqual(quote.options.map(\.cost), [1, 2, 5, 10])
        XCTAssertNil(quote.resetsAt)
    }

    func testGapJustUnderFifteenMinutesDoubles() {
        let previous = UnlockStreak(lastMultiplier: 1, lastEnd: date(2026, 9, 14, 14, 5), dayKey: day)
        let at = date(2026, 9, 14, 14, 19, 59)
        XCTAssertEqual(UnlockPricing.multiplier(after: previous, at: at, dayKey: day), 2)
    }

    func testGapOfExactlyFifteenMinutesResets() {
        let previous = UnlockStreak(lastMultiplier: 4, lastEnd: date(2026, 9, 14, 14, 5), dayKey: day)
        let at = date(2026, 9, 14, 14, 20)
        XCTAssertEqual(UnlockPricing.multiplier(after: previous, at: at, dayKey: day), 1)
    }

    func testMultiplierDoublesWithoutACap() {
        let previous = UnlockStreak(lastMultiplier: 32, lastEnd: date(2026, 9, 14, 14, 5), dayKey: day)
        let at = date(2026, 9, 14, 14, 6)
        let quote = UnlockPricing.quote(after: previous, at: at, dayKey: day, nextDayStart: dayStart)
        XCTAssertEqual(quote.multiplier, 64)
        XCTAssertEqual(quote.options.map(\.cost), [64, 128, 320, 640])
    }

    func testADifferentDayStartsFresh() {
        let previous = UnlockStreak(lastMultiplier: 2, lastEnd: date(2026, 9, 14, 4, 5), dayKey: "2026-09-13")
        let at = date(2026, 9, 14, 4, 10)
        XCTAssertEqual(UnlockPricing.multiplier(after: previous, at: at, dayKey: day), 1)
    }

    func testResetTimeIsTheEndPlusTheGap() {
        let previous = UnlockStreak(lastMultiplier: 2, lastEnd: date(2026, 9, 14, 14, 13), dayKey: day)
        let at = date(2026, 9, 14, 14, 14)
        let quote = UnlockPricing.quote(after: previous, at: at, dayKey: day, nextDayStart: dayStart)
        XCTAssertEqual(quote.multiplier, 4)
        XCTAssertEqual(quote.resetsAt, date(2026, 9, 14, 14, 28))
    }

    func testResetTimeStopsAtTheDayStart() {
        let previous = UnlockStreak(lastMultiplier: 1, lastEnd: date(2026, 9, 15, 3, 50), dayKey: day)
        let at = date(2026, 9, 15, 3, 51)
        let quote = UnlockPricing.quote(after: previous, at: at, dayKey: day, nextDayStart: dayStart)
        XCTAssertEqual(quote.multiplier, 2)
        XCTAssertEqual(quote.resetsAt, dayStart)
    }
}

import XCTest

@testable import MyTimeCore

final class MigrationTests: XCTestCase {
    private let appID = "8E1A1C2B-0000-4000-8000-000000000001"
    private let created = 1_793_000_000.0

    /// A schema-1 payload as 0.1.0 wrote it.
    private func v1File(
        modes: [String], pending: [[String: Any]] = [], numbers: [String: Int] = [:],
        grants: [[String: Any]] = []
    ) throws -> Data {
        let app: [String: Any] = ["id": appID, "name": "Discord", "bundleIDs": ["com.hnc.Discord"], "modes": modes]
        let day: [String: Any] = [
            "focusSeconds": 900.0, "tokensEarned": 1, "tokensSpent": 2, "backedOff": 0, "quickLooks": 1,
            "replies": 2, "claimedAwaySeconds": 0.0, "unclaimedAwaySeconds": 0.0,
        ]
        let state: [String: Any] = [
            "schemaVersion": 1,
            "settings": ["numbers": numbers, "apps": [app]],
            "pending": pending,
            "tokens": 7,
            "progressSeconds": 120.0,
            "tokensDayKey": "2026-10-24",
            "grants": grants,
            "bookings": [],
            "daily": ["2026-10-24": day],
            "weekly": ["2026-W43": ["emergencyUses": 0, "allowanceForfeited": false]],
            "history": [],
            "clock": ["offsetSeconds": 0.0, "lastWall": created, "lastContinuous": 1000.0, "bootSessionID": "BOOT-A"],
        ]
        return try StateCodec.seal(JSONSerialization.data(withJSONObject: state))
    }

    private func pendingMode(_ mode: String) -> [String: Any] {
        [
            "id": UUID().uuidString, "createdAt": created, "applyAt": created + 6 * 3600,
            "change": ["setMode": ["appID": appID, "mode": mode, "enabled": true]],
            "summary": "Turn on something for Discord",
        ]
    }

    private func migrated(_ data: Data) throws -> PersistedState {
        guard case let .migrated(state) = StateCodec.decode(data) else {
            XCTFail("expected .migrated")
            throw CocoaError(.coderReadCorrupt)
        }
        return state
    }

    func testQuickLookAndReplyBecomeUnlock() throws {
        let state = try migrated(v1File(modes: ["quickLook", "reply", "booked"]))
        XCTAssertEqual(state.schemaVersion, 2)
        XCTAssertEqual(state.settings.apps[0].modes, [.unlock, .booked])
        XCTAssertEqual(state.tokens, 7)
        XCTAssertEqual(state.daily["2026-10-24"]?.focusSeconds, 900)
        XCTAssertNil(state.unlock)
        XCTAssertNil(state.unlockStreak)
        XCTAssertEqual(
            state.migrationNotice,
            "Quick look and Reply mode are now Unlock. Choose 1, 2, 5, or 10 minutes at the gate, 1 token a minute. "
                + "An Unlock bought less than 15 minutes after the last one costs twice as much.")
    }

    func testReplyAloneLeavesUnlockOff() throws {
        let state = try migrated(v1File(modes: ["reply", "booked"]))
        XCTAssertEqual(state.settings.apps[0].modes, [.booked])
        XCTAssertTrue(state.migrationNotice?.hasSuffix(" Unlock is off for Discord because Quick look was off.") == true)
    }

    func testPendingQuickLookEnableBecomesUnlockWithTheSameTime() throws {
        let state = try migrated(v1File(modes: ["reply"], pending: [pendingMode("quickLook")]))
        XCTAssertEqual(state.pending.count, 1)
        let id = try XCTUnwrap(UUID(uuidString: appID))
        XCTAssertEqual(state.pending[0].change, .setMode(appID: id, mode: .unlock, enabled: true))
        XCTAssertEqual(state.pending[0].applyAt, Date(timeIntervalSince1970: created + 6 * 3600))
        XCTAssertEqual(state.pending[0].summary, "Turn on Unlock for Discord")
    }

    func testPendingReplyAndRemovedSettingChangesAreDropped() throws {
        let number: [String: Any] = [
            "id": UUID().uuidString, "createdAt": created, "applyAt": created + 3600,
            "change": ["setNumber": ["key": "replySeconds", "value": 300]], "summary": "Reply mode length: 3 min → 5 min",
        ]
        let state = try migrated(v1File(modes: ["quickLook"], pending: [pendingMode("reply"), number]))
        XCTAssertTrue(state.pending.isEmpty)
        XCTAssertTrue(
            state.migrationNotice?.hasSuffix(" 2 pending Quick look or Reply mode changes were canceled.") == true)
    }

    func testRemovedSettingNumbersAreDropped() throws {
        let state = try migrated(v1File(modes: ["quickLook"], numbers: ["quickLookMaxTokens": 5, "gatePauseSeconds": 10]))
        XCTAssertEqual(state.settings.numbers, ["gatePauseSeconds": 10])
    }

    func testActiveLegacyGrantKeepsRunning() throws {
        let grant: [String: Any] = [
            "id": UUID().uuidString, "appID": appID, "kind": "quickLook", "createdAt": created,
            "expiresAt": created + 60, "tokensSpent": 2,
        ]
        let state = try migrated(v1File(modes: ["quickLook"], grants: [grant]))
        XCTAssertEqual(state.grants.map(\.kind), [.quickLook])
    }

    func testCurrentVersionDecodesAsOk() throws {
        let fresh = PersistedState.fresh(now: date(2026, 10, 24, 10), timeZone: testTZ)
        XCTAssertEqual(StateCodec.decode(try StateCodec.encode(fresh)), .ok(fresh))
    }

    func testUnknownVersionIsTampered() throws {
        let payload = try JSONSerialization.data(withJSONObject: ["schemaVersion": 3])
        XCTAssertEqual(StateCodec.decode(try StateCodec.seal(payload)), .tampered)
    }

    func testNoticeCanBeDismissed() throws {
        let state = try migrated(v1File(modes: ["quickLook"]))
        var core = EngineCore(state: state, timeZone: testTZ)
        core.dismissMigrationNotice()
        XCTAssertNil(core.state.migrationNotice)
    }
}
